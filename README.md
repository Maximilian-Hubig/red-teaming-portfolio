# 🔴 AI Red Teaming Portfolio

> Fokus: AI/LLM Security · Prompt Injection · Jailbreaking · Local Model Testing

---

## 👤 Über mich

Ich beschäftige mich mit der Sicherheit von KI-Systemen und Large Language Models (LLMs).
Mein Ziel ist es, Schwachstellen in AI-Anwendungen zu finden, zu dokumentieren
und verantwortungsvoll zu melden.

---

## 🎯 Schwerpunkte

- **Prompt Injection** – Manipulation von LLM-Verhalten durch präparierte Eingaben
- **Jailbreaking** – Umgehung von Sicherheitsmechanismen in AI-Modellen
- **LLM Web App Testing** – Sicherheit von AI-gestützten Webanwendungen
- **Local Model Analysis** – Testing von lokal ausgeführten Modellen
